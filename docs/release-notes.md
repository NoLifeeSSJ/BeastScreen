# BeastScreen 0.1.0 development preview

Native Windows WPF player, libmpv playback abstraction, local SQLite library and playlists, JSON settings, background scanning, local metadata/thumbnails, direct streaming controls and the maintenance installer are implemented in source.

This file is a release-note candidate, not a publication record. Windows 11 playback/manual acceptance, clean-machine installer lifecycle and the complete native corresponding-source/license inventory remain required. There is no Windows 10/native ARM64 qualification, DRM playback, DVD menu backend or packaged website extractor. No signing credentials or signatures have been invented.
