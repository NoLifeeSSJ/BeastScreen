# Milestones and release gates

Statuses describe evidence, not just source-code presence.

The user now reports BeastScreen working on Windows 11. Record this as basic-operation confirmation; detailed device/input/installer checks remain unrecorded. Continue independent implementation and Windows Server automation without treating the report as a complete acceptance matrix.

1. **Repository and playback prototype — automated Windows Server playback passes; Windows 11 acceptance pending.** WPF HWND host, libmpv lifecycle/events, D3D11/WARP configuration, rendering ADR and smoke runner work in CI with a real synthetic H.264/AAC fixture. The required Vulkan loader builds successfully. Physical audio, input focus, subtitle appearance and GPU/software fallback must be observed on Windows 11 before this milestone is fully accepted.
2. **Playback controls — implemented, Windows acceptance pending.** Open/seek/queue/tracks/speed/chapters/loop/subtitle/picture/audio/diagnostics are wired. No placeholder buttons are presented as a delivered feature. Audio device selection currently uses an engine device list plus its exact name rather than a friendly device picker.
3. **Library/playlists/preferences — core and helper tests pass; Windows product acceptance pending.** SQLite, resume, favourites, history, bookmarks, backup/restore, relocation, search/pagination, selected-folder scans, embedded tags, bounded thumbnails/cover art, page-based artist/album/genre grouping and playlist import/export exist. Rich music browsing across full collections needs further product work.
4. **Streaming/compatibility — controlled Windows Server network and representative codec matrix pass.** Actual-player tests cover ranged HTTP, bounded/cancelable retries, radio live controls, static unencrypted HLS/DASH and private URL persistence guards. Native tests decode five video and five audio combinations. Hardware/physical networks, remaining codecs/protocols, yt-dlp, disc title UI and disc backend investigation remain unaccepted.
5. **Windows interface/integration — shell implemented; acceptance pending.** Dark accessible chrome, list/grid, native airspace approach, shortcuts, single instance and media-key messages exist. Windows system media transport controls, high-DPI/multi-monitor, keyboard/screen-reader acceptance remain outstanding.
6. **Installer/release — v0.1.0-preview.1 published and public install/uninstall passed.** Release ZIPs exclude mpv/FFmpeg; the installer downloads and verifies their pinned upstream archives directly. App/runtime notices and matching application/Vulkan source accompany publication. User authorized a preview after reporting Windows 11 operation. Full Windows 11 clean-machine lifecycle, interactive/hardware checks and actual shortcut/association qualification still gate a stable release. Tagged builds must pass build, playback and controlled lifecycle tests, followed by an actual public-download install/uninstall check. Signing remains unavailable.
